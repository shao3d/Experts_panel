## Причина и исправление

У `84c76e2` общий CI №37008251523 завершился ошибкой на `Run backend tests`;
остальные четыре проверочных задания прошли. Deploy workflow был успешен.

Чистая копия отслеживаемых файлов воспроизвела зависимость пяти тестов от
локального корпуса: digest, соседние посты, существование fixture keys и два
сценария верификации цитат. Там предполагались реальные посты и локальный
`backend/.venv/bin/python`, отсутствующие в чистом окружении CI.

- Digest и show теперь проверяются на временной искусственной SQLite-базе:
  три страницы, точное множество постов, ограничение соседей, изоляция экспертов.
  Используются настоящие SQL-запросы и read-only соединение; подменяется только
  корень тестового backend.
- Верификация цитат проверяет CLI, lookup-протокол, положительный ответ,
  выдуманную цитату, отсутствующий ключ и аннотацию WARNING без живой БД.
- Проверка настоящих fixture keys перенесена под существующий явный флаг
  `SEARCH_PROBE=1`. Она не удалена; исторический baseline не переписан.
- CI устанавливает зависимости для реального MCP contract test. Отсутствие
  Bun на CI теперь ошибка; на локальной машине без Bun остаётся явный skip.
- Итоговый job больше не зелёный при упавшем, отменённом или пропущенном
  обязательном задании. Устаревшая надпись про готовность Railway убрана.

Runtime Скаута, поисковые пороги, проверка цитат и production DB не менялись.

## Проверки

Полный backend-набор запущен в отдельной копии внутри `dev/output/`, без
рабочих `.env`, секретов или корпуса, с фиктивными ключами и пустой тестовой БД.
После ремонта: **583 passed, 22 skipped**, ноль падений. Изменение числа skip
на один — явное вынесение проверки настоящего корпуса в поисковый стенд;
остальные opt-in проверки остались такими, как были. MCP contract test выполнен.

Изначальное локальное воспроизведение также обнаружило два свойства самого
изолированного окружения: отсутствующие npm-зависимости и отсутствие отдельного
Git index для проверки tracked agent files. В копии установлены зависимости
из lockfile и создан локальный индекс; тест контракта Git не ослаблялся.

YAML workflow разобран; shell-код summary проверен с четырьмя исходами:
success → exit 0; failure/cancelled/skipped → exit 1.
