# Ручная проверка дрифта визуальных каналов, 2026-10-08

Status: Evidence snapshot — production data released
Last updated: 2026-10-08

## Причина и границы

Владелец поручил обновить базу по визуалам. Scoped-синк пяти визуальных каналов и индексация новых постов прошли, но автоматический дрифт через `xiaomi-token-plan-sgp/mimo-v2.6-pro` остановился на `quota exhausted`. Повторы остановили до записи ошибочных решений. Подготовленную staging-БД со свежими постами и VideoHub выпустили штатным режимом `DB_UPLOAD_ONLY=1`; затем владелец отдельно поручил субагенту Sol 6.1 medium разобрать незавершённый дрифт.

Это **разовая ручная проверка**, а не переключение автоматического рантайма. SSOT штатной модели и процедуры — `docs/guides/drift-analysis.md`. Агент работал только со staging и visual-группой; production-БД напрямую не открывал и tracked pipeline не менял.

## Метод и результат

Временный staging-only adapter использовал штатный `DriftSchedulerService` для чтения pending-групп и записи результата. Перед записью он сверял fingerprint исходного поста и комментариев; для каждой темы требовал дословную цитату из комментария. Темы получили embedding через существующий сервис и метку `drift_checked_sol61_manual`. После каждой записи проверялось уменьшение scoped pending на единицу. Временный adapter удалён после проверки.

| Эксперт | Проверено и сохранено | Есть дрифт | Нет дрифта |
| --- | ---: | ---: | ---: |
| acidcrunch | 13 | 1 | 12 |
| cgevent | 32 | 9 | 23 |
| iideyalogiya | 3 | 0 | 3 |
| neyrograph | 7 | 3 | 4 |
| strangedalle | 7 | 5 | 2 |
| **Всего** | **62** | **18** | **44** |

Все 65 исходных групп и комментарии прочитаны, включая четыре длинных обсуждения по частям. Повторная проверка подтвердила 62 ожидаемых ID, валидность записанного JSON и эмбеддинги для всех 18 групп с дрифтом: размер 768, конечные значения, единичная норма. Среди обработанных групп нет статуса `error`. Всего сохранены 24 отдельные темы. Примеры: экономика автоматизации труда; безопасность запуска JavaScript и раскрытие IP; способ публикации анимаций через GitHub Pages вместо MP4.

Три группы оставлены `pending`, потому что без отсутствующего медиа нельзя честно установить тему исходного поста: `19511` содержит только подпись канала, `19561` — фразу «А погнали в казино» без видео, `19564` — ссылку на «эту историю» без её текста. Медиа этих трёх групп не проверялось; вердикты для них не выдуманы.

## Production

После проверки результатов агентом выполнено отдельное штатное продвижение staging-БД через `DB_UPLOAD_ONLY=1 ./scripts/update_production_db.sh`. Скрипт проверил SQLite, создал backup, атомарно заменил production-БД, перезапустил `panel` и получил успешный `/health` в **22:05 UTC**. В production теперь есть 62 проверенных решения; три группы остаются pending. Это не меняет автоматический выбор MiMo для будущих циклов дрифта.
